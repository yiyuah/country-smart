# 全站檢查與修正紀錄

## 文案與介面

- 移除首頁「我們一步一步教您」結尾句點。
- 移除首頁、導覽列、頁尾與一般操作頁反覆出現的競賽、展示版、模擬與虛擬機型文字。
- 來源說明集中到「關於本站與服務狀態」；工作台、統計及 JSON 管理移到工作人員專區。
- 所有教學改為較短的具體步驟，移除虛構機型及不必要的技術敘述。
- 調整標題換行、選取回饋、字體比例、手機控制列、卡片留白與確認視窗焦點。

## 流程與資料

- 求助頁不再為未選家電的使用者自動填入洗衣機與洗程問題。
- 家電類別切換後不沿用前一台的問題。
- 移除假影像辨識動畫與未使用模型的辨識宣稱；相片由使用者確認種類。
- 不再預選服務、日期與時段；必要內容未選完不能往下。
- 門市體驗只允許門市方式；到府與安裝需求使用相容的方式。
- 地區只作需求整理，不假裝成正式門市或即時名額。
- 服務結果改為儲存需求摘要，清楚說明未送出；新增可回看的需求清單。
- 諮詢重點儲存後可回讀，不再只有成功訊息。
- 保留舊版家電、需求與諮詢紀錄，避免升級後遺失資料。

## 程式錯誤

- 改善 hash 路由與瀏覽器歷史，頁面返回、瀏覽器返回及前進保持一致。
- 修正跳至主要內容被誤當成不存在頁面的問題。
- 每次教學採獨立進度與識別，避免跨家電共用學習紀錄；重新整理可恢復。
- 評分與問題回饋按最後一次選擇計算。
- 自動播放等朗讀結束才切換，暫停及離開頁面會停止。
- 修正非整數服務流程參數可能導致頁面錯誤。
- 相片及相機採失效識別，避免離開頁面後非同步結果改寫新頁面。
- 相機離開或切到背景時關閉，不能繼續擷取已停止的預覽。
- 確認視窗在返回其他頁面時關閉。
- 儲存失敗時不再宣稱下次一定看得到資料。
- 匯入資料驗證欄位、長度、檔案大小與重複編號，顯示文字經過 HTML 轉義。

驗證詳見 `results.json`，包含完整流程、錯誤狀態、資料升級、相機與語音替代流程、影片及響應式版面。
