# 全國智家｜全國智慧居家

家電不會用？我們一步一步教您

## 開啟網站

在 Windows 解壓縮整個專案後，用 Edge 或 Chrome 雙擊 `index.html`。請保留 `styles.css`、`data.js`、`icons.js`、`app.js` 與 `assets` 在同一個資料夾。

網站可離線使用，不需要 Node.js、npm、帳號、API Key 或後端。既有頁面請按重新整理，載入這次修正。

## 主要操作

- **掃描家電**：使用相機、上傳照片，或直接選擇種類。相片只供使用者確認家電，不推測品牌或型號。
- **我的家電**：新增種類與放置位置、修改、查看教學或刪除。新使用者的清單從空白開始；舊版已有的資料保留。
- **教學中心**：洗衣機、冷氣機、電視、電子鍋、冰箱，共 20 個主題、60 個步驟。可播放、暫停、前後切換、重新觀看與朗讀。
- **學習紀錄**：每次學習有自己的進度；重新整理後可繼續，首頁提供最近一次的學習入口。問題回饋與評分可修改。
- **找人協助**：查看已選問題、儲存諮詢重點、選擇服務地區，或整理門市／到府需求。
- **服務需求**：選擇服務、家電、地區與希望的日期時段，再儲存摘要。尚未選齊必要內容時，不能繼續；門市體驗不會被安排成到府服務。
- **我的服務需求**：從頁尾或求助頁查看已儲存的摘要，也可以新增或刪除需求。
- **服務流程**：七個可切換階段，搭配原始照片與對應入口。
- **使用導覽**：在「第一次使用」或「服務介紹」中選擇導覽，從洗衣機開始練習。只有主動開啟導覽才顯示步驟提示。
- **閱讀輔助**：標準／大字／超大字、高對比、朗讀與停止朗讀。支援鍵盤操作、確認視窗、明確焦點與減少動態效果。

## 服務狀態與資料

網站的一般頁面以使用者操作為主，不反覆顯示競賽、展示或開發說明。來源與服務狀態集中在「服務介紹 → 關於本站與服務狀態」。

目前真正可用的是本機教學、圖片預覽、影片播放、家電管理、學習進度、服務需求整理及儲存。影像辨識模型、電話客服、正式門市查詢、預約送出與派工並未串接。

因此：

- 沒有假稱 AI 已辨識品牌型號。
- 沒有虛構實際門市地址、電話或可預約名額；地區選項只用來整理需求。
- 完成服務需求時顯示「服務需求已儲存／未送出」，不會顯示預約成功。
- 日期與時段為希望的安排，實際服務需由門市確認。
- 電話頁不會撥出電話，提醒使用購買憑證或保固書上的聯絡方式。
- 不要求姓名、電話、住址、帳號或付款資料；相片不會上傳或寫入永久儲存。

家電、需求、諮詢重點與學習紀錄保存在目前瀏覽器的 LocalStorage。不同瀏覽器、電腦或網址來源不共用資料。若儲存受限制，網站會告知關閉後可能不保留。

舊版的家電清單、服務摘要與諮詢紀錄會在升級時保留，重新載入不會重複搬移。

## 工作人員專區

頁尾的「工作人員專區」集中提供顧問工作台、使用紀錄與 JSON 地區管理，一般使用者動線不會進入這些管理功能。

工作台以已儲存的需求為主，不再自行建立虛構客戶。紀錄與處理狀態按需求分開儲存。狀態變更不會聯絡顧客或產生真實派工；本機工作區沒有正式人員登入與企業權限系統。

使用紀錄以匿名事件計算使用次數、教學完成、問題解決率與滿意度，與範例數據分開。統計不代表真實到店、來電或企業營運成果。

- 解決率取每次學習最後的問題回饋；未填者不納入。
- 滿意度取每次學習最後一次有效評分。
- 重設統計不會刪除家電、需求或學習進度。
- 可匯出匿名 JSON；不含照片、姓名、電話或住址。
- 最多保留 5,000 筆事件、60 次學習進度與 100 份服務需求。

地區 JSON 範例為 `assets/stores.json`，每筆需包含 `id`、`name`、`city`、`district`、`note`。可從專區匯入，最多 100 筆、100 KB，並可恢復預設。資料不應含個人資訊或未核實的門市聯絡方式。

## 素材與教學

`assets` 保留提供的四張 JPG 與 MP4 原始檔名及內容，使用相對路徑。影片在「服務介紹」中播放，是服務宣傳素材，不作為特定機型的按鍵教學。

教學說明基本操作與保養概念；按鍵、容量、模式與清潔方式依各產品說明書為準，不提供自行拆修指引。

## 驗證範圍

以 Windows Microsoft Edge 與 Playwright，直接用 `file://` 開啟測試：

- 完整選家電、學習、問題回饋、求助與服務需求儲存流程。
- 五種家電、20 個獨立主題、60 個步驟。
- 不同教學進度隔離、重新整理恢復、修改回饋及評分。
- 家電新增／修改／檢視／刪除、確認視窗與焦點。
- 地區篩選、服務與地點相容性、必填狀態、日期與草稿保存。
- 需求清單、諮詢重點回讀、顧問紀錄與舊資料升級。
- 影片實際解碼、播放、暫停、重播、靜音與失敗提示。
- 19 個一般頁面的內部文案掃描。
- 約 30 個頁面及異常路由，在 320、390、700、1024、1440、1920px 的水平溢出檢查，以及超大字模式。
- 儲存與語音不可用時的替代提示。
- 虛擬相機擷取成功、相機無權限、離開與背景關閉鏡頭。
- 用可控制的語音事件驗證播放會等朗讀結束，暫停後不再切換步驟。

結果在 `qa/results.json`；完整測試為 `qa/test.cjs`，補充檢查為 `qa/review.cjs`。沒有在使用者本人的實體相機、手機、中文語音輸出或螢幕閱讀器上進行人工驗收，也未宣稱已完成 WCAG 認證。

`qa` 是開發驗證資料；使用網站不需要安裝測試工具。ZIP 僅打包可攜式網站檔案與本說明。
